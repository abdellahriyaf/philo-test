# موقع مراجعة الفلسفة
**البنية الثابتة لكل درس (مفهوم):** المفاهيم المحيطة ← ثلاثة محاور، لكل محور: الإشكال، الأقوال، الآراء الحجاجية، الحجاج، الأفكار الحجاجية.
الدرس الأول في كل مجزوءة يبدأ أيضاً بـ«التقديم» (تعريف المجزوءة وعنوانها والمفهوم العام ...).

- **إضافة درس جديد:** انسخ `content/_template-first-subunit.html` (الدرس الأول في المجزوءة) أو `content/_template-subunit.html` (الثاني)، املأ المحتوى، واحفظه باسم `content/uX-sY.html`.
- **تعديل درس:** افتح الملف على GitHub واضغط أيقونة القلم. التنقل العلوي يُبنى تلقائياً من أقسام الصفحة (`data-nav`).
- **العناوين والألوان وترتيب الدروس:** `assets/config.js`. **التصميم العام:** `assets/site.css (+ assets/home.css للصفحة الرئيسية)`.
- **محلياً:** `python -m http.server` ثم افتح `localhost:8000`.

- **ملاحظة:** يمكنك لصق صفحة HTML كاملة في `content/uX-sY.html`؛ يُؤخذ منها العنوان والأقسام فقط ويُطبَّق عليها تصميم الموقع تلقائياً (يجب أن تستعمل نفس أسماء الأصناف: `block` و`problem` و`quotes` ...). بعد الحفظ على GitHub انتظر دقيقة ثم اضغط Ctrl+Shift+R.
